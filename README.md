# ECOLSUR — versión estática para GitHub Pages

1. Crea un repositorio en GitHub.
2. Sube todo el contenido de esta carpeta a la raíz del repositorio. `index.html` debe quedar en la raíz.
3. Abre **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/(root)`, y guarda.

Esta versión no requiere ASP.NET MVC ni Razor para mostrarse. Conserva los recursos en `Content` y `Scripts`.

**Formulario:** actualmente abre el cliente de correo mediante `mailto:`; no guarda ni envía datos a un servidor.

Google Fonts y Material Design Icons requieren conexión a internet.
